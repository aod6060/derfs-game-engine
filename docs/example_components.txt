Here are all of the component that are currently supported
in the game engine currently

mesh-component

{
    "type": "mesh-component",
    "mesh": "[mesh-name]",
    "texture": "[texture-name]",
    "uv-scale": [uv-scale]
}

camera-component

{
    "type": "camera-component",
    "fov": 45.0,
    "znear": 0.1,
    "zfar": 1024.0
}

static-body-component

{
    "type": "static-body-component",
    "collision-shape": {
        [see below for more detail]
    },
    "groups": [
        [see below for more details]
    ],
    "masks": [
        [see below for more details]
    ]
}

collision-shape [for static/dynamic/kinematic/trigger]

    "type": "static-plane",

}

groups ~ These and names for the collision filter system they are located in
the "global.json" under the "physics" section of the json file. Here are a list
all the current groups

    "static",
    "crate",
    "player",
    "triggers"
]
